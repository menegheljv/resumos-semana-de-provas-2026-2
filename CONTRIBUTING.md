# Como contribuir

Este repositório é público para facilitar o estudo coletivo.

- Mantenha o conteúdo organizado na pasta da matéria correta.
- Cite a fonte quando adicionar uma definição, dado ou exemplo.
- Prefira explicações curtas, objetivas e revisáveis.
- Não publique dados pessoais, provas não autorizadas ou materiais protegidos por direitos autorais.
- Abra uma issue quando houver dúvida e um pull request quando houver uma melhoria pronta.
